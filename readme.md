# TheCollapse

JavaScript / HTML / CSS · Node.js · Docker

---

## 概要

**TheCollapse** は、チャット・履歴管理・アカウント機能を備えた Web アプリケーションです。  
Node.js をバックエンドとし、Docker による環境構築に対応しています。

---

## 技術スタック

| 分類 | 内容 |
|------|------|
| フロントエンド | HTML / CSS / JavaScript |
| バックエンド | Node.js (index.js) |
| インフラ | Docker |

---

## セットアップ

### Docker を使う場合

```bash
docker build -t thecollapse .
docker run -p 3000:3000 thecollapse
```

### ローカルで直接起動する場合

```bash
npm install
node index.js
```

## 機能一覧

| 機能 | 説明 |
|------|------|
| 💬 チャット | リアルタイム送受信・過去ログ表示・メッセージ削除の即時反映 |
| 🐦 X 検索 | Yahoo!リアルタイム検索を利用した X(旧Twitter) の投稿・画像検索 |

| 👤 アカウント | 個人データ管理・端末間でのデータ同期 |
| 🔄 履歴同期 | 複数端末・複数タブ間での履歴・ブックマーク同期 |

## v1.6.1

### X(旧Twitter)がちゃんと使えるようになった

- プロキシ経由で X(x.com / twitter.com)を開いたとき、メールアドレス・ユーザー名の入力欄がフォーカスされず、Apple / Google / 電話番号でのログインボタンも押せなかった問題を修正した。
- 原因はアプリ内の二重 iframe(トップページ → ブラウザUI → プロキシ iframe)の中で X を動かしていたこと。X 側のフレーム検出・React のイベント処理・OAuth ログインのポップアップがこの構造だと壊れるため、入力もボタンも反応しなくなっていた。
- X / Twitter のときだけ、プロキシ経由のまま「新しいウィンドウ(about:blank のトップレベル)」で開くように変更した。サービスワーカーがサイトをトップレベル文書として扱うため、入力欄のフォーカス・ログインボタン・OAuth ポップアップすべてが通常通り機能する。
- プロキシ iframe に `popups` 権限を追加し、X のログインポップアップがブロックされないようにした。
- 検索ショートカット・アドレスバー・ブックマーク・履歴のどれから X を開いても新しいウィンドウで開くよう統一した。

## v1.6.0

### X(旧Twitter)検索タブを追加した

- チャットの隣に「X」タブを追加し、X(旧Twitter)の投稿や画像を検索できるようになった。
- キーワードを入力すると、画像付き投稿をギャラリー形式で一覧表示する。画像をタップすると拡大表示できる。
- 「画像 / 動画 / すべて」「人気順 / 新着順」を切り替えられる。`#ハッシュタグ`・`ID:ユーザー名`・`A OR B`・`A -B` などのクエリ演算子にも対応している。
- 「もっと見る」で続きの投稿を読み込める。各投稿からそのまま X を開ける。
- センシティブと判定された画像はぼかして表示し、タップで表示を切り替えられる。
- ※ Yahoo!リアルタイム検索を利用しているため、日本語の投稿が中心になる。

## v1.5.1

### アプリとしてインストールできるようになった

- スマートフォンやパソコンのホーム画面にこのサービスをアプリとして追加できるようになった。インストール後はブラウザのバーなどがないすっきりした画面で起動できる。
- インストール可能な環境ではメニューに「ホームに追加」ボタンが表示される。インストール済みの場合は自動で非表示になる。

### ブラウザ機能を開いてもURLが変わらないようになった

- 検索やショートカットからブラウザ機能を使う際、以前は別ページに移動してアドレスバーのURLが変わっていた。今後はトップページの上にブラウザ画面が重なって表示される形になり、URLはそのまま保たれる。
- 「戻る」操作でブラウザ画面を閉じてトップに戻れるようになった。

## v1.5.0

### ゲーム機能を削除した

- ゲームページおよびすべてのミニゲームを削除した。今後はチャット・履歴・アカウントのメイン機能の改善に集中する。

### アカウント関連のバグを修正した

- 操作のタイミングが重なったとき、保存したはずの履歴やタブが消えることがある問題を修正した。
- 複数の読み込みが同時に走っても、データが重複したり矛盾したりしないようにした。
- ログアウトや別アカウントへの切り替え時に、前のアカウントのデータが残ってしまう問題を修正した。

### 複数端末・複数タブでの同期が機能するようになった

- ひとつのタブで履歴やブックマークを変更すると、開いている他のタブにも自動で反映されるようになった。タブを切り替えたタイミングでも最新の状態に更新される。

## v1.4.0

- アイコンを設定しているアカウントでメッセージが送れなくなる問題を修正した。
- メッセージのアバター・入力欄・返信バー・リアクション周りの見た目を細かく調整し、全体の見やすさを改善した。

## v1.3.4

### チャット機能の拡張

- 自分のメッセージを後から編集できるようになった。編集したメッセージには「(編集済み)」と表示される。他の人のメッセージは管理者であっても編集できない。
- メッセージへの引用返信に対応した。引用部分をクリックすると元のメッセージへ飛んでハイライト表示される。
- メッセージへの絵文字リアクションが使えるようになった。同じリアクションをもう一度押すと取り消せる。
- メッセージを削除する前に確認のダイアログが表示されるようになった。
