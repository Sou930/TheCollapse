# TheCollapse

JavaScript / HTML / CSS · Node.js · Docker

---

## 概要

**TheCollapse** は、チャット・履歴管理・アカウント機能を備えた Web アプリケーションです。  
Node.js をバックエンドとし、Docker による環境構築に対応しています。

---

## 技術スタック

| 分類 | 内容 |
|------|------|
| フロントエンド | HTML / CSS / JavaScript |
| バックエンド | Node.js (index.js) |
| インフラ | Docker |

---

## セットアップ

### Docker を使う場合

```bash
docker build -t thecollapse .
docker run -p 3000:3000 thecollapse
```

### ローカルで直接起動する場合

```bash
npm install
node index.js
```

## 更新履歴

### v1.5.1

#### 📲 ホーム画面に追加（PWA 対応）
- **「ホーム画面に追加」に対応**: Web アプリマニフェスト（`manifest.webmanifest`）とアプリ用アイコン（192/512/maskable/Apple Touch）、アプリシェル用サービスワーカー（`pwa-sw.js`）を追加し、スマートフォン／PC のブラウザから **ホーム画面・アプリとしてインストール**できるようにした。インストール後は単体アプリ（standalone）として `.com`（トップ）から起動する。
- **インストールボタンの追加**: インストール可能な環境ではナビに「ホームに追加」ボタンを表示し、ワンタップでインストールできるようにした（インストール済み／スタンドアロン起動中は自動的に非表示）。
- **プロキシ用 SW との分離**: アプリシェル用 SW は、UltraViolet のプロキシ用サービスワーカー（`/sw.js`, scope `/service/`）とは別スコープ（`/`）で動作し、プロキシ通信・Bare・WebSocket・API・ユーザーデータには一切介入しない設計とした。

#### 🪟 ブラウザの「埋め込み」表示（URL を `.com` のまま保持）
- **ページ遷移せずに埋め込み**: 検索・ショートカット・Browser ボタンからプロキシブラウザを開く際、これまでは `/.../go.html` へ**ページ遷移**していたためアドレスバーの URL が変わっていた。今回からトップページ上に**全画面オーバーレイ（iframe）としてブラウザ UI を埋め込む**方式に変更し、**URL は `.com`（トップ）のまま**保持されるようにした。
- **戻る操作で閉じる**: ブラウザの戻るボタン（および埋め込み内の「ホームに戻る」）でオーバーレイを閉じてトップに戻れるよう、履歴（History API）と `postMessage` で親子ページを連携させた。

### v1.5.0

#### 🎮 ゲーム機能の削除
- **Game ページ・ミニゲームを撤去**: ナビゲーションの「Game」ボタン、ゲーム一覧ページ（`game.html`）、ゲーム詳細ページ（`play.html`）、ゲーム定義（`game.json`）、および各ミニゲーム（2048 / snake / tetris）を削除した。今後はチャット・履歴・アカウントといったコア機能に注力する。

#### 🐞 アカウント関連のバグ修正
- **保存の競合による更新喪失（lost update）を修正**: これまで履歴・タブ・ブックマークなどの保存処理がそれぞれ独立にサーバーからデータ全体を読み込み→一部だけ書き換え→全体を書き戻していたため、500ms のデバウンス窓内で複数の保存が重なると後勝ちで互いの変更を上書きし、**履歴やタブが保存されない／消える**問題があった。ログイン中ユーザーのデータを単一のインメモリドキュメントとして共有し、各保存はその同じオブジェクトを書き換えるだけにすることで競合を解消した。
- **同時読み込みの重複防止**: キャッシュ未構築時に複数の読み込みが並走しても、ロード Promise を共有して常に同一ドキュメントを返すようにした。
- **ログイン/ログアウト/アカウント削除時のキャッシュ整合性**: ユーザー切り替え時にデータキャッシュを確実にリセットし、ログアウト・削除前に保留中の書き込みを flush（削除時は破棄）するようにした。

#### 🔄 履歴・タブ同期の有効化
- **複数端末・複数タブ間で履歴/ブックマークが同期**: `BroadcastChannel` と `localStorage` シグナルでデータ変更を他タブへ通知し、タブが再びアクティブになった際（`visibilitychange`）にはサーバーから最新データを読み直すようにした。受信側は開いている履歴/ブックマークパネルを自動で再描画する。
- **書き込みの一貫性向上**: UV Cookie の定期保存も共有ドキュメント経由に統一し、タブ保存・Cookie 保存が互いを上書きしないようにした。

#### 🏷️ ドキュメント整理
- 機能一覧からミニゲームの記載を削除し、アカウント・履歴同期の説明を実態に合わせて更新した。

### v1.4.0

#### 🐞 バグ修正
- **UI（タブ・URLバー）非表示時の表示崩れ修正**: プロキシブラウザ（go）で「タブ・URLバーを隠す」ボタンを押すと、バーを消した分の上部に空白が残り、画像のように本来のコンテンツがずれて表示されるバグを修正。UI 非表示時はコンテンツ領域を画面上端まで広げ、隙間が生じないようにした。

#### 🔐 ログインの利便性向上
- **ユーザー名の大文字小文字を区別しない**: ログイン時にユーザー名の大文字小文字どちらでも認証できるようにした（登録名はそのまま保持・表示）。重複登録も大文字小文字を無視して防止する。

#### 🏷️ バージョン表示の自動化
- トップページのバージョンバッジを `readme.md` の「更新履歴」内で**一番上に記載されたバージョン**から自動取得するようにした。今後はこのファイルを更新するだけでサイト上の表示が追従する。

#### 💬 チャットの修正・改善
- **送信できない不具合の修正**: アイコン付きアカウントで `[ws error] Max payload size exceeded` が発生し、メッセージが送信できなくなる問題を修正。WebSocket の最大フレームサイズをアイコン（data URL）込みでも扱えるサイズへ引き上げ、テキスト本文の長さ制限とは独立して管理するようにした。
- **デザイン調整**: メッセージのアバター/余白・入力欄・返信バー・リアクションまわりの細部を整え、視認性と一体感を向上。

### v1.3.4

#### 💬 チャット機能の拡張
- **メッセージ編集機能**: 自分のメッセージを編集できるようにした。編集可否はサーバー側で送信者本人かを確認（admin であっても他人の発言は改変不可）。編集後は「(編集済み)」バッジを表示。
- **メッセージへの返信（リプライ）**: 引用返信に対応し、会話の流れを明確化。引用元の本文・送信者名はサーバーが元メッセージから確定し、なりすましや細工本文の混入を防止。引用部クリックで返信元へジャンプ・ハイライト。
- **絵文字リアクション**: メッセージにリアクションを付けられるようにした（CSS のみで未実装だった機能を実装）。ホワイトリスト方式の絵文字のみ許可し、同一ユーザーの再押下でトグル解除。1 メッセージあたりのリアクション種類数に上限を設けて肥大化・DoS を抑止。
- **メッセージ削除確認**: 削除前に確認ダイアログを表示し、誤削除を防止。

### v1.3.1

#### 🔐 アカウント機能の脆弱性修正（重大なセキュリティ修正リリース）
##### 修正した脆弱性
- **パスワードハッシュの全公開**: `worksheets/data/<username>.json` および `account.json` が静的配信で誰でも GET でき、`passwordHash` が漏洩していた → データファイルは**ログイン中の本人のみ**アクセス可能にし、認証情報は静的配信外の `auth-data/auth.json` でサーバーが一元管理。
- **弱いハッシュ方式（djb2 / 32bit・ソルト無し）**: 容易に逆算可能だった → **scrypt + ランダムソルト**へ変更。
- **クライアント側のみの認証**: パスワード照合がブラウザ内のみで、誰でも任意ユーザーのデータファイルを `PUT` で上書き（なりすまし・改ざん）できた → サーバー側で**セッション（HttpOnly Cookie）による認証・認可**を実装。書き込みは本人のファイルのみ許可。
- **機微フィールドのデータ混入**: データファイルへ `passwordHash` / `admin` 等を保存できた → サーバー側でこれらのフィールドを保存時に除去。
- **アカウント列挙**: ログイン応答の差異でユーザー有無が判別できた → 応答時間とメッセージを均一化。
